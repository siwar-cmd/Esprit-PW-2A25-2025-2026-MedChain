CHANGEMENTS DE BASE DE DONNÉES
==============================

Table: intervention
- Champ: niveau_urgence
  - Type: INT ou VARCHAR
  - Valeurs supportées: 1, 2, 3, 4, 5 (ou NULL)
  - Labels affichés: "Faible", "Modérée", "Élevée", "Critique", "Extrême"

MIGRATION DES ANCIENNES DONNÉES
===============================

Si vous avez des anciennes interventions avec des valeurs NULL ou "0":

UPDATE intervention SET niveau_urgence = 2 WHERE niveau_urgence IS NULL OR niveau_urgence = 0;

INSTALLATION DE TCPDF
====================

URGENT: Pour utiliser l'export PDF, TCPDF doit être installé.

Option 1 - Via Composer (Recommandé):
  cd c:\xampp\htdocs\projet\projet
  composer require tecnickcom/tcpdf

Option 2 - Manuelle:
  Voir le fichier: INSTALL_TCPDF.txt

TESTS À EFFECTUER
=================

1. Créer une nouvelle intervention:
   - Sélectionnez un niveau d'urgence de 1 à 5
   - Vérifiez l'enregistrement en base

2. Voir la liste:
   - Vérifiez que le niveau s'affiche avec la couleur appropriée
   - 1 = Vert (Faible)
   - 2 = Jaune (Modérée)
   - 3 = Rose (Élevée)
   - 4 = Rouge (Critique)
   - 5 = Rouge foncé (Extrême)

3. Voir les détails:
   - Cliquez sur l'œil pour voir tous les détails
   - Le niveau doit afficher le label texte

4. Exporter en PDF:
   - Cliquez sur "Exporter en PDF"
   - Vérifiez que le fichier se télécharge correctement
   - Si erreur TCPDF: installez TCPDF (voir INSTALL_TCPDF.txt)

STRUCTURE ACTUELLE DE LA BASE
============================

Table: intervention
├── id (INT, PK)
├── type (VARCHAR)
├── date_intervention (DATETIME)
├── duree (INT - minutes)
├── niveau_urgence (INT - 1-5)
├── chirurgien (VARCHAR - nom du médecin)
├── salle (VARCHAR)
├── description (TEXT)
└── created_at (TIMESTAMP)

NOTES IMPORTANTES
=================

- Le champ "niveau_urgence" utilise des nombres (1-5) en base
- L'affichage convertit automatiquement les nombres en labels texte
- Les anciennes interventions sans niveau affichent "Non défini" en gris
- La fonction getNiveauUrgenceLabel() du modèle est réutilisable
- TCPDF est optionnel: sans lui, vous ne pouvez pas exporter en PDF
